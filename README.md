# Music Platform - Музыкальная площадка

Современный шаблон музыкальной платформы на React + TypeScript + Vite + TailwindCSS.

## 🚀 Возможности

- **Современный стек**: React 19, TypeScript, Vite, TailwindCSS
- **Аудио плеер**: Полный контроль воспроизведения с хуком `useAudioPlayer`
- **Адаптивный дизайн**: Полная поддержка мобильных устройств
- **Типизация**: Строгая типизация всех компонентов и данных
- **Компоненты**: Готовые переиспользуемые компоненты
- **Анимации**: Плавные анимации и переходы
- **Темная тема**: Стильный темный дизайн с акцентными цветами

## 📁 Структура проекта

```
src/
├── components/          # Переиспользуемые компоненты
│   ├── Header.tsx      # Шапка с навигацией
│   ├── HeroSection.tsx # Главный экран
│   ├── MusicPlayer.tsx # Аудио плеер
│   └── TrackCard.tsx   # Карточка трека
├── hooks/              # Кастомные хуки
│   └── useAudioPlayer.ts
├── types/              # TypeScript типы
│   └── index.ts
├── utils/              # Утилиты и хелперы
│   └── index.ts
├── pages/              # Страницы приложения
├── assets/             # Статические файлы
├── App.tsx             # Главный компонент
├── main.tsx           # Точка входа
└── index.css          # Глобальные стили
```

## 🛠 Установка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр сборки
npm run preview
```

## 🎨 Компоненты

### Header
Навигационная панель с логотипом и меню.

### HeroSection
Главный экран с призывом к действию, статистикой и популярными треками.

### MusicPlayer
Полнофункциональный аудиоплеер с:
- Управление воспроизведением
- Прогресс бар
- Регулировка громкости
- Перемешивание и повтор
- Очередь воспроизведения

### TrackCard
Карточка трека с обложкой, информацией и кнопкой воспроизведения.

## 🎯 Типы данных

Шаблон включает полную типизацию для:
- `Track` - музыкальный трек
- `Artist` - исполнитель
- `Album` - альбом
- `Playlist` - плейлист
- `User` - пользователь
- `PlayerState` - состояние плеера

## 🎨 Стилизация

TailwindCSS с кастомной конфигурацией:
- Цветовая палитра (primary, dark)
- Кастомные анимации
- Утилитарные классы (btn-primary, card, input-field)
- Градиентные тексты

## 🔧 Расширение

Шаблон готов к расширению:
- Добавьте новые страницы в `src/pages/`
- Создавайте компоненты в `src/components/`
- Подключите бэкенд через API
- Добавьте аутентификацию
- Интегрируйте реальную базу данных
